## Task 1: Cookie host-only cho ekid (phiên độc lập)

**Files:** `src/lib/supabase/cookies.ts`, `src/lib/supabase/middleware.ts`.

- [ ] **Step 1:** `cookieOptions(base, opts?: { hostOnly?: boolean })` — khi `hostOnly` thì KHÔNG set `domain` (chỉ `secure + sameSite`).
```ts
export function cookieOptions(base?: Record<string, unknown>, opts?: { hostOnly?: boolean }): Record<string, unknown> {
  if (process.env.NODE_ENV === "production") {
    if (opts?.hostOnly) return { ...base, secure: true, sameSite: "lax" as const };
    return { ...base, domain: ".nooi.net", secure: true, sameSite: "lax" as const };
  }
  return { ...base };
}
```
- [ ] **Step 2:** `updateSession` (middleware.ts) xác định host; truyền `{ hostOnly: host === "ekid.nooi.net" }` vào MỌI lời gọi `cookieOptions(...)` (set + clear).
- [ ] **Step 3:** Verify: `npx tsc --noEmit`; đọc code xác nhận nhánh ekid host-only. Commit.
